제타 채팅 어워즈

채팅에서 공유·선정·보상·후속 영상으로

채팅 공모를 중심으로 구성한 UGC 이벤트·기능 제안입니다. 다이어그램과 독립적인 예시 UI로 흐름을 설명합니다.

기능 제안 · 미집행 · 가제

공식 제타 행사나 채택·개발 완료 사례가 아닙니다. 가상 데이터로 제안의 구조를 설명하며 실제 계정·신청·AI와 연결하지 않습니다.

01 · 아이디어

나만 보기 아쉬운 채팅을 공유하고, 우수한 이야기를 선정해 원작자와 채팅 제출자에게 보상하는 UGC 이벤트를 제안합니다. 선정 채팅을 AI 드라마 롱폼과 숏폼·광고로 후속 활용하는 구상입니다.

첫 회차는 파일럿으로 보고 결과에 따라 정기 개최를 검토합니다. 참여·유입·피스 사용 변화는 기대 효과를 확인할 가설이며 실제 성과가 아닙니다.

02 · 무엇을 제안했는지

보조 도식 · 유저 투표 대안과 추가 검토안

기본안과 분리한 선택 대안입니다. 원안의 투표 병행 구상은 내부 1차 선정, 유저 투표 기반 2차 선정, 투표수와 내부 평가를 반영한 최종 순위입니다. 반영 비율·동점 처리는 미정입니다.

04 · 작업물

6개 화면으로 행사 진입, 대화 메뉴, 포크 공개·접수, 마이페이지, 프로필, 다른 유저의 이어하기를 설명합니다. 기존 화면 구조 참고와 추가 제안은 실선·점선 및 텍스트로 구분합니다.

독립 예시 UI 열기 →

실제 신청·업로드·AI 호출·보상 지급은 없습니다. 예시의 프로필 진입은 마이페이지를 거치며, 플롯·피드는 프로필 안의 탭입니다. 투표 대안은 예시 UI에 넣지 않았습니다.

아직 결정하지 않은 부분

  • 포크의 저장 구간·공개 설정과 실제 개발 구조
  • 공개 포크 탭 위치, 미리보기·저장·접수의 화면 구성
  • 권리 확인·동의 양식, 분량 기준, 보상 배분·동일인 처리

05 · 검토 메모

행사의 중심은 채팅 경험을 공유·선정·보상·후속 콘텐츠로 잇는 흐름입니다. 포크는 이를 설명하는 기능 제안이며, 공개한 기록과 이후 개인 대화를 구분해 검토합니다. 품질 심사와 참여 경험을 함께 설계하되, 원안·공식 사례·추가 대안의 경계를 유지합니다.
