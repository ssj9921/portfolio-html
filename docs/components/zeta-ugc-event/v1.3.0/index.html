기능 제안 · 미집행 · 가제

01 · 아이디어

나만 보기 아쉬운 채팅을 공유하고, 우수한 이야기를 선정해 원작자와 채팅 제출자에게 보상하는 UGC 이벤트를 제안합니다. 선정 채팅을 AI 드라마 롱폼과 숏폼·광고로 후속 활용하는 구상입니다.

첫 회차는 파일럿으로 보고 결과에 따라 정기 개최를 검토합니다. 참여·유입·피스 사용 변화는 기대 효과를 확인할 가설이며 실제 성과가 아닙니다.
