01 · 아이디어

지금 가격에 더해, 처음 관심을 가졌던 순간의 가격도 함께 볼 수 있다면 어떨까요? 관심종목을 등록할 때의 가격을 저장하고 현재가와 비교하는 기능을 제안했습니다.

개인적인 비교 기준이 재방문과 종목 탐색으로 이어질 수 있다는 기획 가설에서 출발했습니다. 실제 사용자 조사나 성과 측정은 수행하지 않았습니다.

02 · 무엇을 만든 건지

즐겨찾기 목록 안에서 ‘오늘 등락’과 ‘등록 이후’를 전환하는 인터랙티브 프로토타입입니다. 가상 종목과 가격을 사용하며 실제 시세 조회·계좌 연결·거래 기능은 없습니다.

  • 비교 기준 전환과 종목별 상세 정보 펼침
  • 더미 현재가 변경에 따른 상승·하락·보합과 요약 갱신
  • 관심종목 추가·해제, 재등록 시 새 기준 가격 저장

등록 이후 변화율은 (현재가 − 등록 가격) ÷ 등록 가격 × 100입니다. 실제 매매 수익률과 다르며, 보유 수량·수수료·세금·배당은 반영하지 않습니다.
