프로그래밍은 팀원 1명 담당

AI 활용과 에셋 제작

Whisk → VARCO 3D → Blender → Mixamo(캐릭터 리깅) → Unity의 흐름으로 모델을 제작하고 게임에 적용했습니다.

제출 발표 자료 기준 지형을 제외한 에셋 95개를 VARCO 3D로 제작했습니다. 외부 텍스처도 사용했으며, 모든 시각자료를 AI로 생성한 것은 아닙니다.
